# 개발 기록

## 2026-11-17 (1주차)

**한 일**
- 메시지 형식을 JSON Lines(JSON + `\n`)로 정함. TCP 스트림에서 메시지 경계를 나누기 위함
- `protocol.py`: 수신 버퍼에 쌓고 `\n` 단위로 잘라 읽는 `Connection` 클래스, 송신 lock
- `server.py`: 2명 접속 → 경기 진행 → 종료 후 다시 대기. 버저 판정은 `threading.Lock`으로 처리
- 오답/답변 시간 초과 시 상대에게 답변권 이동, 버저 시간 초과 시 정답 공개
- 연결 끊김 시 남은 참가자에게 `OPPONENT_LEFT` 전송
- `client_cli.py`로 터미널 2개에서 경기 진행 확인

**테스트 결과**
- `tests/scenario_test.py`: 정답, 오답→상대에게 넘김, 시간 초과, 버저 미입력, 공개 중 버저 거절, 오답 노트 → 모두 통과
- `tests/buzz_race.py` 50회: 답변권이 두 명에게 간 경우 0회
  - 답변권 획득 분포가 한쪽에 치우침 (P1 7회 / P2 43회). 판정 기준이 "서버가 먼저 처리한 요청"이라
    로컬 환경에서는 스레드 스케줄링 순서가 결과를 좌우하는 것으로 보임 → 보고서에 언급할 것

**막힌 점 / 해결**
- Windows에서 `accept()`가 블로킹 중이면 Ctrl+C가 안 먹음 → 리슨 소켓에 1초 타임아웃을 주고 반복
- `Timer.cancel()`이 이미 실행 중인 콜백을 막지 못함 → 토큰 번호로 오래된 타이머를 무시

- 기말 범위 문제 15~20개 작성
